# BitChord Desktop (Electron Shell)

A dedicated, standalone desktop Electron shell for **BitChord** that runs the web build without requiring `web/` source code modifications or any installed browser extension.

---

## Features

- **No Browser Extension Needed**: The Electron main process natively replaces all browser extension capabilities.
- **Native CORS & Origin Spoofing**: `session.defaultSession.webRequest` automatically injects CORS permissions and rewrites `Origin`/`Referer` headers for YouTube InnerTube (`music.youtube.com/youtubei/`, `www.youtube.com/youtubei/`) and `googlevideo.com` streams (including removing headers for `c=VISIONOS`).
- **Discord Rich Presence**: Speaks directly to your local Discord desktop app via named pipe (`\\pipe\\discord-rpc-0`) using `@xhayper/discord-rpc` with BitChord Application ID `1543679166967193620`. Shows track title, artist, album, live playback timeline countdown, and action buttons.
- **Preload Extension Polyfill**: Injects `window.chrome.runtime.sendMessage`, `window.chrome.runtime.connect`, and `window.postMessage` bridge relay directly into the main world. The web player detects the bridge as `present` on startup without missing a beat.
- **Media Playback Controls**:
  - Global hardware Media Keys (`Play/Pause`, `Next`, `Previous`)
  - Optional global keyboard shortcuts (`Ctrl+Alt+Space` for play/pause, `Ctrl+Alt+Right` for next, `Ctrl+Alt+Left` for previous)
  - Windows Taskbar Thumbnail Toolbar (ThumbarButtons) for play/pause, next, and previous directly from the taskbar preview.
- **Auth & Session Management**: Clean popup handling for YouTube / Spotify logins, storing cookies in Electron's persistent session store.
- **Web App Caching**: Includes a script to mirror `https://bitchord-8bw.pages.dev/home` locally for offline or instant loading.

## Getting Started

### Prerequisites
- Node.js >= 20
- npm >= 10

### Installation
From the `electron/` directory:
```powershell
npm install
```

### Build & Run
To compile TypeScript and start the Electron application:
```powershell
npm run build
npm start
```

For live development with auto-recompile:
```powershell
npm run dev
```

---

## Offline Caching

To download and mirror the latest deployed web app locally:
```powershell
npm run cache-web
```
This fetches the app shell and assets into `electron/cached-web/`.

To launch BitChord in offline mode from this local cache:
```powershell
$env:BITCHORD_OFFLINE="1"
npm start
```

│   └── preload/

├── tsconfig.json
├── tsup.config.ts           # tsup bundler config
